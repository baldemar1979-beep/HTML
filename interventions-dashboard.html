Interventions — CAP KPI (per vehicle, per shift, per calendar day)

Vehicle-shifts (sortable)

A vehicle-shift is one vehicle on one calendar day in either Day (06:01–19:59) or Night (20:00–06:00).
Total Events includes all events in that vehicle-shift after Network Filters. Verified Valid Fatigue includes verified microsleep + verified drowsiness only.
Event Groups counts 15-minute clusters of verified fatigue events (only when 15-min toggle is ON). DFIT Calls counts rolling-window triggers where ≥ DFIT Cap events occur within the DFIT window.
Cap→Email Miles uses straight-line (haversine) distance from the CAP event location to the last email-event location (when both have lat/lon).
